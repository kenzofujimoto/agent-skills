# Companion-skill integration

## ui-ux-pro-max

Use first for new sites and major redesigns. It owns product/style reasoning, design system,
typography, color, spacing, layout, UX, accessibility and general stack guidance. Read an
existing persisted `MASTER.md` before regenerating it.

## motion-site-builder

Owns per-section motion architecture, media contracts, engine selection, implementation,
performance and visual QA.

## scroll-world-browser

Use only for AI media required by the approved motion plan. Pass explicit aspect ratio,
resolution, safe area, first-frame, background, transparency and watermark constraints.

## Existing stack

The project stack wins. Keep Next.js, Vite React, Vue, vanilla HTML or other existing stack
unless migration is part of the user's actual goal.
