# Web3 e ativos digitais / Web3 & Digital Assets

## Roteamento

- **ID:** `web3-digital-assets`
- **Grupo:** Setor público, ciência e ecossistemas
- **Subnichos:** exchanges, wallets, protocols, developer infrastructure, DeFi
- **Intensidade de motion sugerida:** 3–7/10
- **Perfil de risco:** `financial-high-risk`

## Objetivos frequentes

- build trust and clarity
- explain protocol or custody
- drive onboarding or developer adoption

## Prioridades de conteúdo

- risk and security
- how it works
- fees
- network status
- governance
- docs

## Metáforas de movimento adequadas

- transaction flow
- block confirmation
- network graph
- wallet state
- liquidity movement

## Arquétipos recomendados

- `protocol-explainer`
- `wallet-onboarding`
- `developer-docs`
- `trading-product`

## Engines e mídia

**Engines:** DOM/SVG, Motion, GSAP sparingly, WebGL only for meaningful network view

**Mídia:**

- real product UI
- protocol diagrams
- network data
- security evidence

## Conversão

- create account
- connect wallet
- read docs
- explore protocol

## Evitar

- casino visual language
- hidden risk
- unbounded wallet prompts
- decorative token explosions
- claims of guaranteed returns

Essas URLs são sementes de referência. Antes de usá-las, a skill deve abrir a versão atual,
capturar desktop/mobile, verificar acessibilidade e extrair princípios — nunca copiar branding,
assets, textos, layout exato ou assumir que a tecnologia observada anteriormente permanece igual.
