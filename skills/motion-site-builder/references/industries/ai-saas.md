# IA e SaaS / AI & SaaS

## Roteamento

- **ID:** `ai-saas`
- **Grupo:** Tecnologia e B2B
- **Subnichos:** AI products, horizontal SaaS, vertical SaaS, automation, agents, enterprise software
- **Intensidade de motion sugerida:** 5–8/10
- **Perfil de risco:** `standard`

## Objetivos frequentes

- explain a novel product quickly
- demonstrate product value
- capture qualified leads
- build trust in an emerging category

## Prioridades de conteúdo

- clear product promise
- real product UI
- use cases
- integrations
- security and trust
- pricing or access path

## Metáforas de movimento adequadas

- systems assembling
- data flowing
- interface transformation
- progressive disclosure
- cause-and-effect interactions

## Arquétipos recomendados

- `product-demo`
- `product-launch`
- `lead-generation`
- `interactive-storytelling`

## Engines e mídia

**Engines:** Motion, GSAP, DOM/SVG, Three.js only for one abstract showcase

**Mídia:**

- real UI in DOM
- product recordings
- abstract 3D used sparingly
- architecture diagrams

## Conversão

- interactive demo
- request access
- start free
- book demo

## Evitar

- generic purple AI gradients
- fake unreadable dashboards
- decorative code
- holograms without product meaning
