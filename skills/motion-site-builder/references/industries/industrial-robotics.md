# Indústria e robótica / Industrial & Robotics

## Roteamento

- **ID:** `industrial-robotics`
- **Grupo:** Mobilidade, indústria e infraestrutura
- **Subnichos:** industrial robots, automation, factory systems, machine vision, warehouse robotics
- **Intensidade de motion sugerida:** 4–8/10
- **Perfil de risco:** `technical-accuracy`

## Objetivos frequentes

- show capability and reliability
- explain workflows
- support technical evaluation
- generate enterprise leads

## Prioridades de conteúdo

- applications
- payload and reach
- integration
- safety
- case studies
- service

## Metáforas de movimento adequadas

- robot path
- assembly sequence
- exploded view
- digital twin
- throughput flow

## Arquétipos recomendados

- `product-family-explorer`
- `technical-configurator`
- `interactive-diagram`
- `enterprise-lead-generation`

## Engines e mídia

**Engines:** Three.js/R3F, GSAP, SVG diagrams, Motion for controls

**Mídia:**

- exact machine models
- factory video
- technical diagrams
- simulation data

## Conversão

- request quote
- select application
- download datasheet
- contact integrator

## Evitar

- robot spectacle without application
- invented throughput
- heavy 3D on every product card
- unsafe interaction metaphors
