# Reference analysis

Capture representative desktop/mobile states. Analyze layout, hierarchy, type scale,
whitespace, color, image treatment, content rhythm, scroll-linked vs triggered motion,
sticky/pinned sections, text splitting, cursor effects, page transitions, loaders, parallax,
camera behavior and easing.

Detect technology only when observable in source/network or documented. Do not guess a
specific library from appearance alone.

Output `reference-profile.json` with reusable principles, likely patterns, complexity,
performance/accessibility risk, good-fit product types and anti-patterns to avoid.
