# Explorador de mapa

**ID:** `map-explorer`

Rotas, cobertura, propriedades ou projetos; mapa tem função, não decoração.

## Checklist

- Define the primary user task.
- Define the shortest successful path.
- Choose motion only when it clarifies state, hierarchy, continuity or depth.
- Specify mobile and reduced-motion behavior.
- Define success and failure states.
- Validate accessibility and performance before visual polish.
